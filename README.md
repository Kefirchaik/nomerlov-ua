# 🇺🇦 НомерЛов UA — v1.0.0

**НомерЛов UA** — безкоштовна мобільна браузерна гра про колекціонування українських номерних знаків.

## ✨ Можливості

- Ловля випадкових номерних знаків з регіональними кодами України.
- 6 категорій рідкісності, ціни в **ігрових гривнях**, генерація красивих комбінацій.
- Гараж на 24 номери, обрані, фільтрація, сортування, продаж номерів.
- Крамниця: покращення радара, батареї та енергії.
- Щоденна винагорода, досягнення, історія, статистика.
- Локальне автозбереження, експорт та імпорт прогресу.
- Адаптивний дизайн, PWA-інсталяція, підтримка офлайн-режиму.

## 🚀 Розгортання на Vercel

1. Натисніть **Add New → Project** у [Vercel](https://vercel.com/new).
2. Імпортуйте репозиторій `Kefirchaik/nomerlov-ua`.
3. Оберіть **Framework Preset: Other** та **Root Directory: `./`**.
4. Поля **Build Command** та **Output Directory** залиште порожніми.
5. Натисніть **Deploy**. Подальші коміти до `main` автоматично запускатимуть деплой, якщо Vercel інтегровано з GitHub.

Для локального запуску достатньо відкрити `index.html`. Для перевірки PWA та кешування запустіть локальний сервер (наприклад, `python -m http.server 8000`) і відкрийте `http://localhost:8000`.

## ⚙️ Технічні дані

- Чисті HTML, CSS, JavaScript без залежностей, серверної частини та API-ключів.
- Прогрес у `localStorage` (`nomerlov-ua-save-v1`); резервне копіювання у розділі статистики.
- `sw.js` забезпечує офлайн-доступ, `vercel.json` — коректне кешування оновлень.
- Версія: **1.0.0**.
