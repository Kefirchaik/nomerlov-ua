# НомерЛов UA v1.5.0 — складання Android APK

Це **вихідний HTML/CSS/JS-проєкт**, не готовий APK. Зібрати застосунок можна в [HTML to APK Builder](https://play.google.com/store/apps/details?id=com.basitce.htmltoapk). Гра працює в WebView; окремого Android Studio проєкту поки немає.

## Варіант A — автономний застосунок (рекомендовано)

1. Скачайте ZIP репозиторію: https://github.com/Kefirchaik/nomerlov-ua/archive/refs/heads/main.zip
2. У HTML to APK Builder виберіть імпорт **ZIP / Folder** (можливо, в Advanced Mode).
3. Точкою входу встановіть `index.html` (у ZIP є `apk.css`, `apk.js`, `v13.css`, `v13.js`, `icon.svg` тощо). Не імпортуйте один лише `index.html`, інакше залежні файли не завантажаться.
4. Увімкніть JavaScript, DOM Storage / LocalStorage, файловий вибір (для імпорту резервних копій), вбудований download manager (для експорту та PNG-карток) та offline support.
5. У цьому режимі інтернет не потрібний для основного геймплею; відкриття monobank і зовнішніх посилань потребуватиме мережі.

## Варіант B — застосунок із живого сайту

1. У HTML to APK Builder виберіть **Live URL / Website**.
2. Вставте **`https://nomerlov-ua.vercel.app/?apk=1`**. Параметр `apk=1` вмикає спеціальний режим додатка.
3. Цей варіант потребує інтернету під час першого завантаження або роботи без офлайн-кешу. Оновлення сайту можуть надходити автоматично.

## Рекомендовані параметри

| Налаштування | Значення |
| --- | --- |
| App name | НомерЛов UA |
| Package name | `com.kefirchaik.nomerlovua` |
| Version name | `1.5.0` |
| Version code | `15` (або число більше, ніж у попереднього APK) |
| Orientation | Portrait |
| App icon | `icon-512.png` |
| Splash background | `#080a14` |
| Status bar color | `#111525` |
| Navigation bar color | `#111525` |
| Theme | Dark |
| JavaScript / LocalStorage | Enabled |
| File chooser / downloads | Enabled |
| WebView history / Android Back | Enabled, якщо доступно |
| Pull-to-refresh | Off |
| Camera / Microphone / GPS | Не потрібні |
| Vibration | Опційно — для haptic feedback |

У застосунку вже є **HTML splash-анімація**, яка запускається лише у режимі APK і не потребує окремої платної можливості нативного splash-екрану. Якщо доступний системний splash, поставте темний фон та логотип гри.

Для повноекранного режиму перевірте, щоб системні панелі або вирізи дисплея не перекривали кнопки. Стилі підтримують CSS `safe-area-inset-bottom`.

## Збереження та перенесення прогресу

Ключ збережень **`nomerlov-ua-save-v1` незмінний**, однак **сховище веббраузера та сховище APK можуть бути різними**. Тому:

1. На сайті відкрийте «Статистика» → «Експорт прогресу».
2. Збережіть JSON-файл на телефон.
3. Встановіть APK і відкрийте меню `⋯` → «Імпорт».
4. Виберіть JSON-файл і підтвердьте відновлення.

Перед очищенням даних застосунку, видаленням або перевстановленням APK створюйте резервну копію. Щоб наступні збірки ставилися як оновлення, зберігайте **той самий package name і signing keystore** та збільшуйте version code.

## Перевірка перед поширенням

- [ ] Гра відкривається з логотипом і без білих зон на смартфоні.
- [ ] Головний екран, гараж, магазин і статистика відкриваються нижнім меню.
- [ ] Мови перемикаються в меню `⋯`.
- [ ] Ловля номерів, розширення гаража, прокачування та ігрові нагороди працюють.
- [ ] Експорт і імпорт JSON працюють із Android file chooser.
- [ ] PNG-картки зберігаються / надсилаються в Telegram (залежить від Android та WebView).
- [ ] Банка monobank відкривається поза грою.
- [ ] Кнопка Android Back закриває меню/модалку або повертає на головний екран, якщо WebView Builder підтримує history navigation.
- [ ] Якщо обрано ZIP, перевірено запуск без інтернету.
- [ ] На вузьких екранах немає горизонтального прокручування.

**Примітка:** автоматичну поведінку кнопки Android Back, нативний файловий вибір та офлайн-режим потрібно перевірити на фізичному пристрої після складання APK: вони залежать від WebView та параметрів HTML to APK Builder.
