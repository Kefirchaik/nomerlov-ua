# [1.2.2] — 2026-11-10

- Нейтральні назви додаткового формату: «Інші номери» / «Другие номера», «Інші регіони» / «Другие регионы».

- Збережено регіони, формат номерів, локалізацію й наявні колекції; оновлено кеш PWA.

# [1.2.1] — 2026-11-10

- Прибрано прапор РФ із номерних знаків і символ-емодзі біля інформації про улов.
- Підписи змінено на «Формат РФ», «Обидва формати» та «Регіони РФ».
- Збережено механіку, номери, локалізації, сумісність прогресу та код регіону `RUS`.
- Оновлено PWA-кеш для доставки виправлення гравцям.

# [1.2.0] — 2026-11-10

- Кастомні вікна вибору регіону й сортування замість нативних Android-списків; пошук за назвою та кодом.
- Українські й російські номери: UA / RU / змішаний режим; реалістичний окремий макет російського номерного знака.
- Локалізація УКР / РУС, збереження вибору мови.
- Старий прогрес зберігається в `nomerlov-ua-save-v1`.
- Двомовні сторінки конфіденційності й правил, новий кеш PWA v1.2.0.

# Історія версій


## [1.1.0] — 2026-11-10

- Векторні SVG-іконки замість емодзі у всіх основних елементах гри.
- Анімоване відкриття епічних, легендарних і міфічних уловів, синтезовані звуки з окремим перемикачем.
- XP і система рівнів із додатковим досвідом за рідкісні номери.
- Три щоденні квести з винагородами та захистом від повторного отримання.
- Особистий топ-10 уловів, який враховує також продані номери.
- Міграція збережень v1.0.0 без втрати колекції, балансу та стану гри.
- Оновлено кеш PWA.

## [1.0.0] — 2026-11-10

- Перший публічний стабільний реліз НомерЛов UA.
- Українські номерні знаки, шість категорій рідкісності, колекція, крамниця, досягнення.
- Експорт та імпорт прогресу, енергосистема та щоденні бонуси.
- Адаптивний інтерфейс для телефону та комп’ютера.
- Офлайн-режим PWA, оновлюваний кеш для нових публікацій.
- Покращена перевірка збережених даних, захист улову при закритті вкладки під час анімації.
- Сторінки приватності та правил, налаштування Vercel.
